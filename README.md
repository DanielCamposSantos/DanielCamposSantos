## 🚀 Projetos em destaque

### 🚗 GeralCar

Plataforma full stack desenvolvida para gerenciamento e divulgação do catálogo de veículos de uma concessionária.

#### [GeralCar API](https://github.com/DanielCamposSantos/geral-car-api)

Backend desenvolvido com **Java 21 e Spring Boot**, incluindo:

* API REST para gerenciamento de veículos;
* Spring Security;
* PostgreSQL e Spring Data JPA;
* filtros e paginação;
* MapStruct e Bean Validation;
* armazenamento de imagens com Supabase Storage;
* testes unitários com JUnit e Mockito;
* testes de integração com REST Assured e Testcontainers;
* containerização com Docker e Jib.

#### [GeralCar App](https://github.com/DanielCamposSantos/geral-car-app)

Frontend desenvolvido com **Angular e TypeScript**, incluindo:

* catálogo público de veículos;
* busca, filtros e paginação;
* página de detalhes e galeria de imagens;
* integração com WhatsApp;
* área administrativa;
* Reactive Forms;
* Angular Material;
* comunicação com a API através de `HttpClient`;
* autenticação baseada em sessão HTTP.

### 📊 [Auto Slides](https://github.com/DanielCamposSantos/auto-slides)

Aplicação desktop desenvolvida em **Java** para automatizar a criação de apresentações PowerPoint a partir de regiões selecionadas em documentos PDF.

O software permite transformar páginas de PDF em imagens, selecionar visualmente regiões de interesse e inserir automaticamente os recortes em posições definidas por templates PowerPoint.

**Principais tecnologias:** Java, JavaFX, Apache PDFBox, Apache POI, Jackson e Gradle.
